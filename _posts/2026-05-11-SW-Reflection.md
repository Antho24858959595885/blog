My team worked with the Arkansas Civic Action Network to create a website that could help students submit civic action project proposals, track volunteer hours, and receive feedback from an advisor. Since this project was connected to a real community partner, it felt different from a normal class assignment. The goal was not just to make something that worked for us, but to make something that could actually be useful for someone else.

One skill that I think was really important for this project was communication. Since we were building something for a community partner, we had to be very thorough in clarifying the scope and core ideas of the website. It was important to ask questions, listen to what they needed, and then turn those needs into actual pages, tables, and features. I also realized that bigger projects can quickly become overwhelming.

The social need behind this project is connected to civic engagement and helping students participate in their communities. I think the Arkansas Civic Action Network’s approach is effective because it gives students a more structured way to think about service and civic action. Instead of forgetting to record their volunteer work, the website can help them keep track of their hours. Students can also receive live feedback about their approved project work from an advisor. That kind of structure can make civic work feel more real and easier to understand.

This project helped me understand that technical and community work are connected. A website can technically work and still be confusing or not useful, so the design and database need to both be easy to understand. This experience made me see databases less like random tables and more like a way to represent an actual workflow. I still think there are parts of the project that could be improved, but I also think the experience helped me see how software can support community-based work when it is built carefully and with the client’s needs in mind.
